# Web Clipper Setup

Obsidian Web Clipper is an optional browser extension, installed separately from Obsidian community plugins. Select this vault as the destination and configure a clip template in the extension.

Save notes under `4. Knowledge Library/Web Clippings/Websites`, `Videos`, or `X Posts`. Use the Knowledge Template's properties: `author`, `type`, `source`, `topic`, and `tags: [knowledge]`; add `created` for the capture date. Retain the original URL and distinguish quotations from your own notes. No extension settings or accounts are included in this starter.
