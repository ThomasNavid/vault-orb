# Web Clipper Setup

Obsidian Web Clipper is an optional browser extension, installed separately from Obsidian community plugins. Select this vault as the destination and configure a clip template in the extension.

Save notes under `4. Knowledge Library/Web Clippings/Websites`, `Videos`, or `X Posts`. Use the Knowledge Template's properties: `author`, `type`, `source`, `topic`, and `tags: [knowledge]`; add `created` for the capture date. Retain the original URL and distinguish quotations from your own notes. No extension settings or accounts are included in this starter.

## Search in Orb

Open Explore → Web Clippings to search saved titles, authors, source URLs, Topics, tags, and body text. Filter by Websites, Videos, X Posts, source, Topic, or capture date. Refresh after capturing a new note in the browser. Untagged clips remain searchable; use `tags: [knowledge]` to include them in the Knowledge graph too.

Capture the article, selected passage, transcript, or your notes if you want content-based answers. A saved URL alone does not give Smith access to the page or video. Previewing and searching are local; Ask Smith sends the selected material to your configured AI provider.
