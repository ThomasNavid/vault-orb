# Recurring tasks

Create and manage repeating tasks here with **desktop Obsidian alone**. Orb does not need to be running or installed. Enable **Dataview → JavaScript Queries** to use these controls. See [[99. System/Recurring Tasks Setup|setup and date rules]] if the dashboard does not appear.

Complete records the occurrence and advances the same note to its next date. Skip advances without recording completion. All history and undo information stay in the task note. Use these controls for recurring tasks instead of ticking a plain Done property.

```dataviewjs
await dv.view("99. System/99.4 Scripts/recurring-tasks/view");
```
