# Goals

Goals describe outcomes you want to reach. Tasks describe actions you can take. Keep the next action as a task in the existing life or business task list, then link it from the goal note.

## How to use this

1. Pick **one to three active goals** for roughly the next 6–12 weeks. Put later ideas in **Someday** rather than making everything active.
2. Create one note per goal in `0. Home/Goals`, using the [[9. Goal Template|Goal Template]]. Write what "done" means in observable terms. If useful, include a starting point and a number to aim for.
3. Set **Target** when a date helps you focus. Treat it as a planning date that you can revise. Put a genuine external deadline on the relevant task using its **Deadline** field.
4. Link one concrete **Next task**. Give that task a **Planned** date when you intend to work on it.
5. Once a week, check each active goal: record progress, name the obstacle, decide whether to continue or change course, and set the next task. Move **Review** to the following week.

Use **Active**, **Paused**, **Someday**, or **Achieved** for Status. Only active goals need a Review date.

If a goal has no next task or has missed its review date, use the next weekly review to decide what action would move it forward. A missed target is a prompt to reassess the plan, not a reason to hide the goal.
