## The routine

1. Choose one to three active goals, usually a milestone you can reach in roughly 6–12 weeks. Keep later ideas in Someday.
2. Create a note in `0. Home/Goals` using [[Goal Template]], or ask Orb to create one. Give it an observable finish line.
3. Set an optional Target date for focus. A target can change as you learn. Use the task's Deadline (`due`) only for a real latest date.
4. Link one concrete Next task and give that task a Planned date when you intend to work on it.
5. Review weekly: record progress, the obstacle, and your decision and next action. Set Review to the following week.

Statuses are **Active**, **Paused**, **Someday**, and **Achieved**. Only active goals need a Review date. A missing next task, missing Review, or passed target is a prompt to reassess the plan.

Ask Orb “Show my goals”, “Let's review my goals”, or “What can I do today to move my goals forward?” The example goal is fictional and starts in Someday.

The supplied template works with Obsidian's core Templates plugin when you set its folder to `Templates`. Folder-based automatic templating requires your own plugin configuration; Orb creates complete notes without a template plugin.
