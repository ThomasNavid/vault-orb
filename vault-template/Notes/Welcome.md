# Welcome

This is a fictional sample vault for trying Vault Orb. Copy it to a separate folder before experimenting; replace or delete the examples in your copy when ready.

- Ask “Show my tasks” to see [[Example errand]] and [[Example project task]].
- Ask “Show all my goals, including Someday” to see [[Example portfolio goal]].
- See [[Goals]] for the routine and [[Goal Template]] for a manual template.
- Ask “Compare the options in Notes/Example launch options.md in a table” to explore [[Example launch options]].
- Ask “Read Notes/Example meeting.md and summarize the decisions” to inspect [[Example meeting]].
- Ask “Chart the balances in Finance/Example savings.csv in GBP” to try a chart. That CSV contains six fictional monthly balances, not personal financial data.

Orb can search/read Markdown notes, inspect supported spreadsheets, and apply explicitly requested task/goal edits or note appends. Calendar requests need your own optional integration setup. Planning a task does not create a calendar event.

Requests to change the examples write real files in this copy of the vault. Use Orb's Recent changes to inspect and undo its note edits.

## Habits and weekly planning
