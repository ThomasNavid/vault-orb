# Example launch options

This note contains fictional sample content for trying Vault Orb's note comparison and planning features.

## Option A: one-page pilot

- Scope: one page describing the service, one case study, and a contact link.
- Estimated effort: two work sessions.
- Advantage: get feedback quickly with a small amount of writing.
- Tradeoff: less room for detailed project stories.

## Option B: full portfolio

- Scope: three case studies, an about page, and a contact page.
- Estimated effort: six work sessions.
- Advantage: a fuller view of the work for prospective clients.
- Tradeoff: more writing before the first feedback arrives.

These effort figures are illustrative estimates, not measured results or commitments.
