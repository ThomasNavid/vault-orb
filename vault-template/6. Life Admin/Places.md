## Add a place

Create a note in the Places folder using [[10. Place Template|Place Template]], or choose **Save** from a place card in Vault Orb. Orb writes the complete frontmatter itself; it does not run Templater.

Category is free text: Restaurant, Café, Bar, Park, Shop, Hotel, Attraction, Venue, or your own category. Default: Uncategorized. Location can be an address, neighbourhood, or city. Website is optional. Keep additional observations and recommendations in the note body.

## Maps and directions

In Vault Orb, open **Explore → Places** or ask “Find a quiet coffee shop nearby”. A Geoapify key in Settings → Connectors → Places enables the map, nearby search, address lookup, and walking times. Choose a starting address or use current location. Place cards open walking directions in Apple Maps or Google Maps.

Latitude and longitude are optional decimal numbers. Leave them empty if unknown; never invent them. Latitude must be −90 to 90, longitude −180 to 180. Both are required for a pin. Orb can resolve an address for a nearby search, but writes those coordinates to an existing note only when you choose **Save location**. Ambiguous addresses need clarification.

The **With coordinates** table checks that both fields are filled; Orb separately checks numeric ranges. Obsidian displays the editable table without a map plugin. No automatic address conversion or map view is configured in Obsidian itself.
